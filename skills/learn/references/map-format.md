## map.md

`map.md` 는 새 세션이 처음 읽는 파일이라 짧게 둔다. 칸에서 일어난 일은 세션 파일에 두고, 여기에는 상태와 가리키는 경로만 둔다. 칸과 안개는 한 줄씩이다. frontmatter 의 `sources` 에는 논문·문서·레포·옛 노트의 경로나 URL 을 적고, 원문을 복사하지 않는다.

```markdown
---
topic: asyncio
slug: asyncio-event-loop
kind: tech                    # tech | paper | video | repo
status: open                  # open | done(목적지 시험 통과)
destination: "API 100개를 동시에 호출해 결과를 모은다"   # 사용자가 없다고 하면 없음
sources:
  - "PEP 3156 https://peps.python.org/pep-3156/"
sessions: [2026-09-08-1, 2026-09-09-1]
---

- 출처: PEP 3156 — "…" (원문 대목 그대로)
```

칸의 `종류`는 셋이다. `기제`는 안에서 일어나는 일, `주장`은 원문이 해냈다고 말하는 것, `자리`는 레포의 파일·디렉토리·경로 한 홉이다. `상태`는 넷이다.

- `열 수 있음`: frontier다.
- `막힘`: 막는 칸이 아직 안 닫혔다.
- `열림`: 다뤘지만 아직 닫히지 않았다. 설명에 빈칸이 남았거나, 설명을 아직 받지 않았다.
- `닫힘`: 끝난 칸이다.

칸 번호는 주제 전체로 이어 붙인다. 정리와 인계가 번호로 가리키기 때문이다.

## sessions/<날짜>-<n>.md

```markdown
---
status: open                  # open | closed
plan: "칸 2 — 끝 조건: 칸 2 를 닫거나 셋째 판까지 간다"
---

## 칸 2. await 는 제어를 루프에 돌려준다
- 먼저 쓴 것: 없으면 "돌려줄 곳이 없으니 await 에서 그냥 멈춘다" · 예측 "A1 A2 B1 B2" · 높음
- 방향: 안에서, 반대편
- 펼친 것: (방향마다 한 줄 요약. 원문 출력은 lab/directions/2026-09-09-1-칸2.md)
  - 안에서: 루프가 ready queue 에서 다음 handle 을 꺼낸다 — 확인: `lab/02-await.py` 에 queue 를 찍는다
  - 반대편: 기다리는 것이 아니라 비켜 주는 것이다 — 확인: sleep(0) 대신 time.sleep(0)
- 짚은 갈림: "기다린다랑 비켜준다가 다른 말 같아"
- 가르기: `lab/02-await.py` → A1 B1 A2 B2, ready queue [B] → [A] → [B]
- 어긋남: 가설 "sleep 이 스레드를 바꾼다" → 짚은 것: 스레드는 하나(threading.get_ident 동일)
- 설명 1: "await 하면 그 작업이 끝날 때까지 기다린다" → 학생: 처음 보는 입력 3개 중 실행과 맞은 것 1개. 빈칸: "기다리는 동안 다른 코루틴이 도는지 설명에 없음"
- 설명 2: "await 하면 루프에 돌아가고, 루프가 큐의 다음 걸 돌린다" → 학생: 3개 중 3개. 빈칸: 없음(칸 물음 밖의 print 방식만)
- 닫음: 닫힘
- 새로 올린 것: 칸 3, 안개 "취소가 루프에 무엇을 남기나"
```

새 주제의 첫 세션은 칸 앞에 `## 줄기`를 둔다. 갈래가 물은 것과 받은 답을 사용자의 낱말로 적는다. `map.md`의 `## 줄기`는 그 요약이다.

```markdown
## 줄기
- 물은 것: 어떤 문제 때문에 생겼나 · 지금도 있나 · 그때의 대안 · 목적지
- 추측: "스레드가 무거워서 만든 것 같다. 지금도 그 문제는 있다. 대안은 스레드 풀"
- 목적지: "API 100개를 동시에 호출해 결과를 모은다"
- 대조: PEP 3156 대목 → 희석된 것·남은 것 "…"
```

`먼저 쓴 것`·`방향`·`펼친 것`·`가르기`·`설명 n`·`닫음`은 칸마다 늘 있다. `짚은 갈림`·`어긋남`·`새로 올린 것`은 생겼을 때 더한다. `펼친 것`은 네 글이니 한 줄 요약만 두고, 사용자의 말은 다른 줄에 그대로 둔다.

## 옛 노트 옮기기

lab-notes·yt-notes·repo-walk 의 노트를 새 지도로 옮긴다. 옛 노트는 읽기 전용 원문이고 고치지 않는다. slug 는 옛 노트의 디렉토리 이름을 그대로 쓴다. 그래야 다음에 같은 낱말로 찾힌다.

| 옛 것 | 새 자리 |
|---|---|
| 지도 줄(기제, 정거장) | 칸. 칸 번호는 새로 매기고, `세션` 열에 `옛 N`(옛 회차·정거장 번호)을 적는다. 옛 번호가 겹치면 `옛 12(판별기)`처럼 옛 회차 제목을 괄호로 단다. 옛 지도에 기제 사이의 의존이 없으면 기제 칸의 막는 칸은 `—`로 두고, 주장 칸에만 기대는 기제를 적는다 |
| 상태 `됨` | `닫힘`. 단, 옛 판정은 설명만 아는 학생을 거치지 않았으니 `## 정리` 의 그 줄에 `(옛 판정)` 을 붙인다 |
| 상태 `도는 중`·`멈춤`, 회차는 있는데 판정이 없는 것 | `열림`. 단, 막는 칸이 안 닫혔으면 `막힘` |
| 상태 `안 함` | 막는 칸이 다 닫혔으면 `열 수 있음`, 아니면 `막힘` |
| 영상의 판정 표 | 버림을 뺀 주장마다 주장 칸. 판정과 이유는 첫 세션 파일 대신 그 칸의 `세션` 열이 옛 노트를 가리킨다 |
| `모르겠다:`·`open_questions`·열린 물음 | 물음이 서면 칸, 아니면 안개 |
| 옛 `## 정리` 와 사용자가 남긴 결론 | `## 정리` 아래 `옛 노트:` 줄로, 사용자 낱말 그대로 인용 |
| 옛 `## 줄기`·`## 과제`·`## 정체` | `## 줄기` 와 `destination`. 바뀐 과제는 `## 목적지` 에 날짜와 함께 |
| 그 밖의 절(읽기 흐름, 과제 시험, 지도에 줄이 없는 회차) | 물음이면 칸, 사용자가 낸 결론이면 `## 정리` 의 `옛 노트:` 줄, 나머지는 안개 |
| 옛 다음 세션 항목 | 칸이나 안개. 옛 노트가 정한 시작점은 `## 다음 세션` 의 시작 칸으로 옮기고, 그 칸이 `막힘` 이면 막는 칸을 시작 칸으로 둔다 |

`## 다음 세션` 은 옮기는 자리에서 쓴다. 옮긴 지도에는 세션 파일이 아직 없으니, `읽을 것` 은 옛 노트에서 시작 칸에 해당하는 절만 가리킨다.

옛 `lab/` 의 실험을 다시 돌려야 하면, 옛 스크립트는 제자리에서 `PYTHONDONTWRITEBYTECODE=1` 로 돌린다. 출력 경로만 이 주제의 `lab/` 로 준다. 스크립트는 옛 `lab/` 기준의 상대 경로(`repos/` 등)를 읽기 때문에, 옮겨서 돌리면 경로가 깨진다. 돌리는 명령은 `## 다음 세션` 의 `환경` 줄에 적는다.

옛 노트가 길면 지도도 길어진다. 그래도 칸과 안개를 한 줄씩으로 지키면, 다음 세션이 읽을 것은 `map.md` 하나로 남는다.
