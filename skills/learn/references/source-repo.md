# 남의 레포 갈래

레포의 큰 그림은 architecture 다. 무엇이 어디에 있고, 요청 하나가 어느 파일들을 거쳐 나가는가. 어디를 열고 어느 줄을 볼지는 네가 찾고, 사용자에게는 `파일:줄`과 함께 설명한다.

## 정찰

이름과 개수로만 잡고, 네 가지뿐이다.

```bash
git rev-parse --short HEAD; git status --porcelain
git ls-files | sed 's/.*\.//' | sort | uniq -c | sort -rn | head   # 확장자별 개수
git ls-files | cut -d/ -f1 | sort | uniq -c | sort -rn             # 최상위별 개수
head -60 README.md
```

진입점 후보는 이름으로 찾는다. `package.json`·`pyproject.toml`·`Makefile`·`main.*`·`SKILL.md` 같은 것이다. `sources`에는 레포 경로와 HEAD를 쓴다.

## 쓰임새

- **무엇**: 무엇을 하는 레포이고 무엇이 제품인가. README 대목을 붙인다.
- **잘 맞는 곳**: 코드를 읽어야 얻는 것이다. 내부 짜임을 가져가거나, 고치거나, 문서에 없는 동작을 알아야 할 때다.
- **안 맞는 곳**: 문서·README·패키지 사용으로 충분한 때다. 레포가 관리를 멈췄으면(마지막 커밋, archived, `STALE.md` 같은 표시) 여기에 적는다.
- **대안**: 비슷한 일을 하는 다른 레포나, 공식 문서·예제 저장소다. 대안이 이기는 조건을 붙인다.

이유가 오면 갈래를 정한다. 이유를 넘기면 전체 짜임이다.

| 갈래 | 이유의 모양 | 큰 그림의 한 판 따라가기 | 확대의 단위 |
|---|---|---|---|
| 전체 짜임 | "무엇이 어디에 있고 어떻게 나뉘었나" | 대표 사용 하나가 진입점에서 출력까지 거치는 최상위 디렉토리 | 디렉토리 하나, 또는 역할 하나(제품, 사람용 문서, 스크립트) |
| 한 가닥 | "X가 입력에서 출력까지 어느 파일을 거치나" | X 가 거치는 파일의 차례 | 경로의 한 홉(파일 하나의 한 자리에서 다음 파일로 넘어가는 곳) |

## 큰 그림

진입점에서 시작해 한 판 따라가기의 경로를 실제로 읽는다. 경로가 파일 여러 개를 넘으면 맥락을 뗀 서브에이전트 하나에 경로 추적을 맡기고, 홉마다 `파일:줄`과 넘겨주는 값을 받는다.

- **왜**: 정체 한 줄과 README·첫 커밋·설계 문서의 대목이다.
- **한 판 따라가기**: 홉마다 `파일:줄`과 그 자리에서 넘어가는 값이다. 돌려 볼 수 있으면 돌려서 출력을 붙인다.
- **부품**: 최상위 디렉토리나 모듈마다 맡는 일 한 줄과, 서로 무엇을 부르는지다. 흐름이 안 지나는 디렉토리는 이름과 개수만 둔다.

## 자리의 확대

열 파일과 볼 줄 두셋을 `파일:줄`로 짚고, 그 줄이 무엇을 하는지 설명한다. 돌려 볼 수 있으면(스킬 실행, 테스트 하나 써서 실행) 돌려서 보인다. 코드를 바꾸는 실험은 정찰의 `git status`에 안 잡힌 깨끗한 파일에만 하고, 확대를 마치기 전에 되돌린다.

**왜가 걸리면 바깥부터 본다.** "왜 이렇게 했지" 싶은 줄을 만나면, 그 식별자나 설정 키가 나타나는 다른 자리를 따라가 본 **뒤에** 답한다. 그 자리의 문서와 이름만으로 만든 답이 읽기가 틀리는 자리다. 실측에서 숙련자가 `IREC = 0`을 문서대로 "포인터 비우기"로 읽었는데, 실제 목적은 다른 루틴의 최적화를 막는 것이었다(Letovsky & Soloway 1986). 따라가서 없으면 이력을 판다(`git log -S'<식별자>'`, blame). 커밋·PR·이슈에 이유가 있으면 해시와 함께 **인용**하고, 없으면 `짐작:`과 blame이 가리키는 이름을 적는다.

## 닫을 때 더할 것

세션을 닫을 때 `map.md`의 `## 큰 그림` 아래에 둘을 더하거나 갈아 쓴다.

- **옮길 것**: 이 레포에서 `why`에 가져갈 짜임이다. 되풀이되는 짜임에는 이름을 붙인다. 확립된 이름(포트와 어댑터, 커맨드 패턴)이 있으면 그것을 쓰고, 없으면 "이름 없음"으로 둔다. 짜임마다 `파일:줄`을 붙인다.
- **안 본 것**: 전문을 읽은 파일, 일부만 본 파일, 이름만 본 것을 나눠 적는다. 다음 세션이 어디를 믿고 어디를 다시 볼지 아는 단서다.

**이을 때.** `sources`의 HEAD와 지금 HEAD가 다르면, `git diff --stat <HEAD>..HEAD -- <큰 그림의 자리들>`을 돌린다. 바뀐 자리는 큰 그림 줄에 `낡음? (<옛>→<새>)`로 표시하고, 그 자리는 새 HEAD로 읽는다. 바뀐 자리가 없으면 커밋 수만 한 줄로 말한다.
