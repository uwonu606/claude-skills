# 판정 장치와 피드백

## 장치

갈림을 가르는 것은 바깥에서 오는 출력이다. 출처 없이 네가 한 설명은 장치가 아니다. 그런 설명은 세션 파일에 `가설:`로 적고, 장치로 다시 확인한다.

| 칸 | 장치 |
|---|---|
| 기제 | `lab/`의 실험을 실제로 돌린다. 설계는 [`experiments.md`](experiments.md)를 따른다 |
| 주장(논문) | 주장을 받치는 원문 대목. 코드가 있으면 `lab/`에서 축소 재현한다([`source-paper.md`](source-paper.md)) |
| 주장(영상) | `sources/yt-<id>.md`의 `[mm:ss]` 원문. 그다음 저자의 현행 문서, 공식 문서, 원 논문 순이다. 돌려 볼 수 있는 기술 주장이면 기제처럼 실험한다 |
| 자리 | 코드 실행, 테스트 하나, `git log -S'<식별자>'`, blame([`source-repo.md`](source-repo.md)) |

리서치는 지금의 갈림 하나에 답하고 돌아온다. 정정에는 출처를 붙인다. 출처를 못 찾으면 그 갈림을 안개로 올린다.

## 설명만 아는 학생

사용자의 설명을 맥락 없는 서브에이전트에게 준다. 이 서브에이전트는 그 설명만 아는 학생이다. 학생의 예측을 실행이나 원문과 대 보면 오개념이 드러나고, 학생이 적은 "설명에 없음"을 보면 구멍이 드러난다.

```
너는 아래 "설명"만 들은 학생이다. <주제>에 대해 원래 아는 것은 쓰지 않는다.
설명이 말하지 않는 동작은 지어내지 말고 "설명에 없음"으로 적는다. 도구는 쓰지 말고 머리로만 답한다.

설명: "<사용자 설명, 낱말 그대로>"

입력:
1. <처음 보는 입력>
2. ...

입력마다 답 형식:
1. 예측
2. 예측의 각 부분마다 근거가 된 설명 문장(인용), 또는 "설명에 없음"
3. 설명으로 정할 수 없었던 곳 목록
```

**입력을 고른다.** 둘셋을 고르고, 실험·원문으로 답이 확인되는 것만 쓴다. 칸의 핵심을 시험하는 입력을 고르고, 이번 칸에서 사용자가 이미 본 입력과는 하나 이상 다르게 한다. 숨은 상태가 결과를 가르는 입력(순서, 경계, 빠진 연결)이 좋다.

**대 본다.** 판정은 두 갈래로 낸다.

- **어긋난 예측**은 오개념이다. 학생이 그 예측의 근거로 든 설명 문장이 오개념이 들어 있는 자리다.
- **"설명에 없음" 가운데 칸의 물음에 걸린 것**은 구멍이다. 칸의 물음에 걸리지 않는 빈칸(출력 형식, 실행 방법 같은 것)은 버린다.

예측이 실행과 맞아도 구멍이 남을 수 있다. 2026-10-26 asyncio 시험이 그랬다. 순서 규칙이 빠진 설명을 받은 학생이 실제와 같은 순서를 골랐다. 하지만 학생은 그 순서가 "설명에 없는" 가정 둘에 기댄다고 적었다. 그래서 판정에는 예측과 빈칸을 둘 다 쓴다.

**돌려 볼 수 없는 칸**(의견이 담긴 영상 주장 등)에서는 학생에게 "이 설명대로라면 다음 사례에서 무엇을 말하겠나"를 묻는다. 그 답은 원문과 출처에 대 본다. 대 볼 것이 없으면 판정 칸에 `확인 불가`를 적고 그 물음을 안개로 올린다.

## 피드백 모양

피드백은 과제에 붙인다. 사용자에게 붙이지 않는다.

| 하라 | 대신 | 왜 |
|---|---|---|
| 틀린 가설을 가리킨다: "예측은 A 가 먼저라고 했는데, 큐에는 B 가 먼저 들어갔다" | "아깝다", "잘했다", "보통 여기서 헷갈린다" | 주의를 자기로 옮기는 피드백은 셋 중 하나꼴로 학습을 떨어뜨린다 |
| 상태를 보여준다: 변수·순서·큐를 찍은 출력 | 맞음/틀림만 | 정답 여부만으로는 이득이 없다 |
| 왜를 붙인다. 단, 사용자가 가설을 낸 뒤에 | 가설 전에 원인 설명 | 앞질러 온 답은 의존을 낳고 전이를 해친다 |
| 확신 높게 틀린 것은 가설을 받은 뒤 원인과 상태까지 한 번에 | 여러 턴에 걸쳐 힌트로 끌기 | 놀란 순간에 주의가 잡히고 가장 잘 고쳐진다 |
| 막혔다면 상태를 하나 더 보여준다 | 답 | 사용자가 가설을 지을 재료가 부족한 것이다 |
| 학생의 빈칸은 한 번에 하나씩 보인다. 칸의 물음에 가장 가까운 것부터 | 빈칸 목록을 한꺼번에 | 빈칸 하나가 설명의 다음 판 하나다 |
| 실험 중이면 기다린다 | 중간에 끼어들기 | 몰두를 끊으면 피드백이 안 붙는다 |

오개념이 다른 언어·도구·자연어에서 옮겨 온 모델이면, 어디서 왔는지를 `어긋남:` 줄에 적는다.
