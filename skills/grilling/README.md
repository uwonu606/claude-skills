# grilling

계획·결정·아이디어를 한 질문씩 캐물어 합의에 도달하는 인터뷰 스킬. 규칙 원문은 [`SKILL.md`](SKILL.md)에 있고, 여기는 fork 의 출처와 추가분이 왜 이 모양인지의 근거를 적는다.

## 출처

[mattpocock/skills](https://github.com/mattpocock/skills) 의 `skills/productivity/grilling` (folder hash `10b0db6`, 2026-07-07 설치·07-21 갱신본). 원문 인터뷰 지시문은 **자구 그대로** 유지했다 — 문구 변경은 A/B 판정 전에 채택하지 않는 규약이라, fork 는 절만 덧붙인다. 원본의 `agents/openai.yaml`(표시용 매니페스트)은 가져오지 않았다.

## 왜 fork 인가

- 커스텀이 이미 무버전으로 일어나고 있었다. 2026-08-24 fableplan 작업이 래퍼 grill-me 에 design-agreement + `/fableplan` 출구를 덧붙였는데, 그 수정이 git 밖(`~/.agents/skills/`)에 있어 `npx skills update` 한 번에 소리 없이 사라질 상태였다.
- 측정 위임 배선과 질문 유형 커버리지(후보)를 넣으려면 소유가 먼저다.

래퍼 grill-me 는 이 fork 의 "마무리 출구" 절로 흡수하고 symlink 를 제거했다 — 진입점은 `/grilling` 하나다.

## 추가분의 근거

**마무리 출구를 조건부로.** grilling 은 트리거 문구로 자동 발동하므로 무조건 출구는 과잉이다. 과거 그릴링 세션 82개·질문 810건 집계에서 다수가 구현으로 이어지지 않는 판단(범위·취향·순서)이었다.

**측정 위임이 기본값.** 2026-09-02 A/B — 같은 성능 함정 문제(람다가 끼면 승자가 뒤집힘)를 서브에이전트 6개에 위임, 프롬프트의 스킬 언급 유무만 바꿨다:

| 조건 | benchmark 스킬 자발 로드 | 경계(람다 뒤집힘) 실측 | 조건부 결론 |
|---|---|---|---|
| 스킬 언급 없음 | 3/3 (첫 행동) | 3/3 | 3/3 |
| 스킬 명시 | 3/3 (첫 행동) | 3/3 | 3/3 |

- "위임 프롬프트에 스킬 명시 강제"는 이 결과로 **기각**됐다 — 스킬 설명문과 전역 CLAUDE.md 배선을 물려받는 환경에선 불필요. 다만 설명문 단독 조건이 2/3이었다는 09-01 실측이 있어, 배선 없는 환경으로 이식할 때의 보험 한 줄로만 남겼다.
- 컨텍스트 격리는 하니스가 보장하고 같은 실험에서 관찰됐다: 측정 잔해 ~436KB(기록 기준)가 부모 컨텍스트 밖에 머물렀고 압축 보고 6건만 돌아왔다. 무관한 내용이 컨텍스트에 있으면 판정이 흔들린다는 저장소 내 실측은 scoped-commits 의 4·4·4 vs 6·8·4.

## 질문 유형 (참고 자료)

그릴링 세션 82개에서 실제 인터뷰 질문 810건을 뽑아 14유형으로 분류했다 — [`references/question-types.md`](references/question-types.md). 핵심 관찰: 선택지 제시(25%)와 잠그기(17%)가 "묻기→잠그기" 리듬으로 전체의 42%를 차지하고, 흔히 '따져묻기'로 상상하는 유형 — 근거 요구(7건)·트레이드오프(10건)·목적·성공 기준(12건) — 이 최하위권이다.

**유형 커버리지 규칙 — 2026-09-02 A/B 통과 후 채택.** 모의 그릴링(sonnet, 동일 계획 1종·고정 응답자·6턴) 3+3판에서 희귀 4유형 출현이 규칙 없음 **1/12**, 규칙 있음 **11/12**로 갈렸다. 판정은 조건을 가린 블라인드 분류로 했고, 채점자는 조건을 모른 채 "클로징에서 체크리스트를 참조해 빠진 유형을 보충한 판"으로 규칙 있는 3판을 정확히 짚었다. 부수 효과: 규칙 있는 3판 모두 목적·성공 기준 질문이 첫 발화로 당겨졌다 — 규칙이 클로징 점검만이 아니라 질문 선택 전체를 움직인다. SKILL.md 의 문구는 테스트한 변형 그대로다(헤더의 "후보" 표시만 제거).

## 한계

- 위임 A/B 는 셀당 3회, 한 머신(WSL2), 성능 질문 1종, 동일 모델이다. 스킬 설명문 효과와 CLAUDE.md 배선 효과는 분리하지 못했다.
- 유형 분류는 분류 에이전트 3개의 판정 합산이라 개별 건수에 ±수 건의 여지가 있고, 유형 경계(확정 촉구 vs 합의 확인 등)는 구간마다 판정이 갈렸다.
- 커버리지 A/B 는 셀당 3판, sonnet, 계획 1종, 고정 응답자(4턴째부터 마무리 압박)다. 클로징 턴에서 남은 유형 두 개를 한 발화에 묶는 완화가 관찰됐다 — 원문의 "한 번에 하나" 지시와 긴장이 있는데, 규칙 없는 판에서도 클로징 묶음은 나타나 규칙 고유의 부작용은 아니다.
