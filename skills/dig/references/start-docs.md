# 문서에서 출발

사용자가 준 문서가 출발 문서다. 고르거나 더하지 않는다 — 사용자가 고른 것이 사용자가 묻는 범위다.

1. 문서마다 `access.md`의 사다리로 본문을 받는다. 사다리 끝까지 본문이 안 오면 사용자에게 붙여 넣어 달라고 청하고 답을 기다린다. 사용자가 그 문서를 빼라고 하면 출발 문서에서 지운다. 이미지·PDF로 된 문서는 받아서 Read로 읽고 글자로 옮긴다.
2. 원문을 `artifacts/anchor-<n>.md`에 둔다. 머리에 제목, 출처(최종 URL, 파일 경로, 또는 "사용자 붙여 넣기 <날짜>"), 받은 날, 주체(공식 이름·통칭·대표 인물 — 문서에 없으면 `~`)를 적고, 그 아래 본문을 그대로 둔다. 번호는 사용자가 준 순서다.
3. 사용자가 질문을 함께 줬으면 frontmatter `question`에 원문 그대로 둔다. 질문이 없으면 `~`다. 실마리는 질문이 아니라 문서의 줄에서 나온다 — 질문은 노트를 쓸 때 무엇을 앞세울지 정하는 데 쓴다.

**완료 조건:** 사용자가 준 문서마다 `anchor-<n>.md`가 있거나, 사용자가 그 문서를 뺐다. frontmatter `start: docs`, `anchors`가 남은 문서의 출처를 사용자가 준 순서대로 담았다.
