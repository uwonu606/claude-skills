# 여는 법

URL 하나는 아래 **사다리**를 위 칸부터 탄다. 본문이 오면 멈추고, 막히면 — 빈 본문·제목만·403·429·로그인 화면 — 다음 칸으로 간다. 도구 권한이 거부되면 같은 URL을 다른 칸으로 다시 시도하지 않고 바로 4칸 되찾기로 간다. 인용은 사다리로 받은 본문에서만 옮긴다 — 검색 결과의 요약 문장은 열 링크를 고르는 데만 쓰고, 그 링크를 끝까지 못 열면 되찾기다. 개인이 적은 양을 조사하는 도구라 사이트의 robots·약관은 따지지 않는다.

| 자리표시 | 뜻 |
|---|---|
| `<스킬>` | `dig/SKILL.md`가 있는 디렉토리의 절대 경로 |
| `<home>` | `${DIG_HOME:-$HOME/dig-notes}`를 펼친 절대 경로. 로그인 파일 `auth/`가 여기 있다 |
| `<work>` | 그 주제의 `work/` 절대 경로. 임시물은 전부 여기에 둔다 |
| `<raw>` | 그 사람의 `raw/<id>/` 절대 경로. 인용할 원문은 전부 여기에 둔다 — 대조가 이 디렉토리만 본다 |
| `<UA>` | `Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/130.0 Safari/537.36` |

명령에는 자리표시를 채운 값을 쓴다 — Bash 호출 사이에 셸 변수가 남지 않는다. `<dir>`은 카드에 인용할 글이면 `<raw>`, 아니면 `<work>`다.

## 1. 사다리

1. **WebFetch** — 검색 결과 링크, 사용자가 준 URL, 페이지가 건 링크.
2. **curl** — WebFetch가 요약만 주거나 원문(HTML·XML·RSS·JSON·PDF·이미지)이 필요할 때, 그리고 #2의 공개 구조 데이터. 출처에는 `-w`가 찍은 최종 URL을 적는다. PDF와 이미지는 받아서 Read로 읽는다. 자바스크립트로 그리는 페이지도 HTML 안의 `<script>`에 박힌 JSON에 본문이 있는 경우가 많다.

   ```bash
   curl -sSL -A "<UA>" "<url>" -o "<dir>/<이름>" -w '%{url_effective}\n'
   ```

3. **browser.py** — 자바스크립트로 그리는 페이지, 봇 차단, 로그인 뒤의 페이지. 호스트에 맞는 로그인 파일(`<home>/auth/<host>.json`)이 있으면 그 계정으로 연다.

   ```bash
   cd <home> && uv run --quiet <스킬>/scripts/browser.py open "<url>" --out "<dir>/<이름>.txt"
   ```

   stderr의 `auth:` 줄이 어느 로그인을 썼는지 말한다. 돌아온 페이지가 로그인 화면이거나 내용이 가려져 있으면 그 호스트는 로그인이 없거나 만료다. 출력의 `URL:` 줄이 최종 URL이다.

   본문이 접힌 목록·"로그인 후 확인"·첫 쪽만으로 보이면 `--net "<work>/<이름>-net"`을 붙여 다시 열고, `index.tsv`에서 그 내용을 싣고 온 API URL을 찾는다. 그 URL의 쪽·필터 쿼리 파라미터만 바꿔 2칸 curl로 다시 부르고, 로그인 화면이나 401이 오면 같은 URL을 이 칸으로 연다 — `--out` 파일의 첫 빈 줄 뒤가 JSON이다. `index.tsv`가 비면 `--html`로 다시 열어 `<script>`에 박힌 JSON에서 찾는다. 둘 다 없으면 본문 텍스트가 전부다. 출처에는 API URL이 아니라 사람이 열 페이지 URL을 적는다.

4. **되찾기** — 셋 다 막힌 URL은 카드의 "읽은 것"에 **못 연 것**(제목·URL·막힌 이유)으로 남기고, 로그인에 막혔으면 그 호스트를 함께 적는다. 메인이 `SKILL.md` #4에서 모아 사용자에게 건넨다.
   - 사용자가 본문을 붙여 넣으면 `<raw>`에 파일로 두고, 그 링크를 출처로 카드에 넣고 못 연 것에서 지운다.
   - 사용자가 로그인하면 — `cd <home> && uv run --quiet <스킬>/scripts/browser.py login "<url>"`, 창에서 로그인하고 닫는다 — 그 호스트의 링크를 3칸으로 다시 열고, 카드에 넣는다.
   - 사용자가 넘긴 링크는 못 연 것에 남는다.

같은 호스트를 연달아 부를 때는 1~2초 띄운다. 429가 오면 그 호스트는 이번 조사에서 쉰다 — 로그인한 계정이 제한되지 않게.

## 2. 전부를 받는 길

**공개 구조 데이터가 있는 곳은 그것부터** 쓴다. 로그인 없이 전부를 주고, 페이지보다 덜 막힌다.

사이트마다 그런 길이 있는지는 그 사이트를 처음 열 때 찾는다 — 피드, 아카이브 페이지, 공개 API, 페이지가 부르는 JSON. 한 사람의 글 전부나 한 스레드의 댓글 전부가 필요할 때 특히 그렇다. 찾은 길은 `<work>/routes.md`에 한 줄씩 적어, 같은 사이트를 여는 다른 에이전트가 다시 찾지 않게 한다.

**말로 남긴 것** — 영상·팟캐스트는 자막을 받아 인용한다. 출처는 영상 URL에 시각(`&t=<초>`)을 붙인다. 팟캐스트는 같은 회차의 영상이 있는지 먼저 찾는다.

```bash
yt-dlp --skip-download --write-subs --write-auto-subs --sub-langs "<언어>" --sub-format vtt --sleep-subtitles 3 -o "<raw>/yt-%(id)s" "<url>"
```

- `yt-dlp`가 설치돼 있지 않으면 명령 앞에 `uvx `를 붙인다.
- 자막 서버는 같은 자막을 다시 받거나 언어를 여럿 받으면 429로 끊는다. 받기 전에 `<raw>`에 같은 영상 id의 `.vtt`가 있는지 보고, 말한 사람의 언어 하나만 받는다.
- 자동 자막은 다른 언어를 거친 역번역일 때가 있다 — 겉보기엔 멀쩡한 문장이라 읽어서는 티가 덜 난다. 채널이 올린 자막(지역이 붙은 언어 코드)이 있으면 그것을 인용한다.
