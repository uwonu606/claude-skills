# 독자 테스트

이 대화를 모르는 서브에이전트가 독자가 되어 글을 읽는다. 대화를 아는 너는 글에 없는 맥락을 머릿속으로 채워 읽기 때문에, 빈 곳을 스스로 찾지 못한다.

## 넘기는 것

글 전문과 독자 설명만 넘긴다. 독자 설명은 누구이고 무엇을 이미 알고 무엇을 모르는지를 1단계에서 정한 그대로 적는다. 재료, 대화, 사용자의 의도는 넘기지 않는다.

```
너는 아래 독자다: <독자 설명>
이 글을 처음 받았다. 읽고 나서 답해라.
1. 이 글을 읽고 네가 할 일을 한 문장으로.
2. 읽다가 막힌 곳: 무슨 말인지 모르겠거나 앞뒤가 이어지지 않는 곳. 인용과 함께.
3. 처음 보는 낱말이나, 풀이가 필요한 낱말.
4. 믿기지 않거나 근거가 더 있어야 할 주장. 인용과 함께.
답은 위 네 항목으로만 하고, 글은 그대로 둔다.
```

## 남기는 것

돌아온 지적 가운데 독자가 다르게 이해하거나 다르게 행동하게 되는 것만 남긴다. 취향의 문제(이 낱말이 더 좋다 같은 것)는 버린다. 1번의 답이 1단계에서 정한 할 일과 다르면, 그것이 가장 먼저 고칠 곳이다.
