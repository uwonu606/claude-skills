# 상품 상세 API 캐시 실험 노트

## 설정
- `GET /products/{id}` 응답을 Redis 에 60초 동안 캐시한다. 캐시 키는 `cache.py` 의 `make_key` 가 만든다.
- 부하: locust 로 10분 동안 상품 50개를 무작위로 1,000번 조회했다. 웹 클라이언트 880건, 앱 클라이언트 120건.
- 기대: 상품이 50개뿐이라 처음 조회 말고는 대부분 캐시에서 나와야 한다. 목표 hit rate 90% 이상.

## 결과
- hit 72 / 1,000 (7.2%). 웹 요청 880건은 hit 0건, 앱 요청 120건은 hit 72건.
- 실험이 끝난 시점에 만들어진 캐시 키는 928개.
- 응답 p50: 캐시 전 190ms, 캐시 후 182ms.
